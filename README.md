This is the source code for the WebIDE built into Focuscript.

Since it exists in a built state within the Focuscript source code, you can activate it by installing only Focuscript and running `/fs webide`.

이건 Focuscript에 내장된 WebIDE의 소스코드입니다.

Focuscript 소스코드에는 빌드된 상태로 이미 있기 때문에, Focuscript만 설치해도 바로 사용 가능합니다. `/fs webide`로 WebIDE를 활성화 할 수 있습니다.

## UI improvements

- **Simple UI**: cleaner layout + file filter.

- **Themes**: 3 built-in themes (Midnight / Snow / Forest) + custom themes.
